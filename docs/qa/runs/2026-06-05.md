## P0 Bugs — Must fix before release

### B-001 — Gateway registration 401 on `--llm`
`kb-create my-project --llm` → gateway returns 401 during registration → `.env` never written → AI features run on heuristics only. Root: registration endpoint logic or credentials flow broken.

### B-013 — Scaffold missing `segments` on commands
Template generates manifest without `segments` array on each command. Validator requires it. Plugin builds successfully but is completely unusable. Fix: add `segments: ["<group>", "<id>"]` to each command in scaffold template.

### B-014 — `kb-create update` flips registry to npmjs
After install from Verdaccio (`http://localhost:4873`), `kb-create update` logs `[WARN] Registry changed → https://registry.npmjs.org/`. Platform reinstalls from npmjs (older versions) → `cli-commands` loses `findCommand` export → all `kb` commands crash.
